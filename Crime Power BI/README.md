# Crime Analysis Dashboard
## Project Overview
The Crime Analysis Dashboard is a Power BI executive solution developed to deliver comprehensive, actionable intelligence on criminal activity. Built on a dataset of 1,400 reported incidents, the dashboard consolidates critical performance metrics including 
- Total reported crimes
- Resolution time of 58 days
- Response time of 92 minutes

The solution provides multi-dimensional analysis across temporal trends (2025–2026), geographic distribution by state and city, crime typology, arrest outcomes, case status, and severity classification. Key insights highlight elevated incident volumes in Rivers, Edo, and Kaduna States, as well as in the cities of Uromi, Udi, and Zaria, with theft, fraud, and robbery constituting the predominant offence categories.

By integrating these perspectives, the dashboard enables decision-makers to identify priority locations, detect operational inefficiencies, and evaluate the effectiveness of existing response protocols. It serves as a strategic tool for evidence-based resource allocation, targeted intervention planning, and continuous performance monitoring in support of enhanced public safety outcomes.

## Business Problem
Management needs a clear and interactive way to concentrate on reported crimes and understand how response and resolution time result in delayed case closure and reduced operational effectiveness.

The dashboard was designed to answer the following questions:

1. How many crimes were reported?
2. Which crime types occur most frequently?
3. Which states have the highest number of reported cases?
4. Which cities have the highest crime volume?
5. Is crime increasing or decreasing over time?
6. What percentage of cases resulted in arrests?
7. How many cases are still open?
8. Which crimes have the highest severity?
9. What is the average police response time?
10. What is the average resolution time?
11. Which locations require the most attention?
12. What patterns can management learn from the data?
